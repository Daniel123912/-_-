# Игровая и финансовая логика

Источник истины в коде: `lib/domain/economy.dart` (`GameEconomy`).  
Модели: `lib/domain/models.dart`.  
Юнит-тесты: `test/domain/economy_test.dart`.

## 1. Стартовый баланс

| Трек     | Возраст | Баланс |
|----------|---------|--------|
| `junior` | 7–8     | 100    |
| `middle` | 9–10    | 110    |
| `senior` | 11      | 120    |

Создание профиля: `PlayerProfile.fresh` → `AgeTrack.startingBalance`.  
Фаза периода: `planning`, стадия питомца `1`, сытость и настроение `70`.

---

## 2. Начисление валюты

| Источник                    | Сумма                                      | Когда            |
|-----------------------------|--------------------------------------------|------------------|
| Периодический доход         | `40` (+`5` для `junior` и `senior`)        | `startNextPeriod`|
| Верный ответ в задании периода | см. §9                                  | `completeQuest`  |
| Практика из каталога        | **0 монет** (только XP)                    | `completeQuest`  |
| Бонус за все квесты периода | `+10`                                      | `closePeriod`    |

Каждое изменение баланса пишется в `lastFeedback` (источник и сумма).

**Обновление заданий периода:** набор `activeQuestIds` ротируется каждые **5 минут** (`questRefreshInterval`). В демо-режиме обновление доступно сразу (кнопка на экране заданий). При загрузке приложения вне демо, если интервал прошёл, набор сменяется автоматически.

## 3. Распределение бюджета

Перед периодом сумма делится на корзины: **обязательное / желаемое / копилка** + опционально **подарить**.

Правила:

- `plan.total ≤ balance`
- суммы ≥ 0
- **`plan.mandatory ≥ 1`** (иначе план отклоняется)
- после `confirmPlan` фаза → `playing`, план фиксируется

### Рекомендуемые доли (`recommendedPlan`)

| Трек     | Обязательное | Желаемое | Копилка | Подарить |
|----------|--------------|----------|---------|----------|
| `junior` | 45%          | 20%      | 25%     | 10%      |
| `middle` | 40%          | 25%      | 25%     | 10%      |
| `senior` | 35%          | 25%      | 30%     | 10%      |

Остаток округления уходит в копилку. При ненулевом балансе обязательная корзина не бывает нулевой.

## 4. Обязательные, необязательные и подарочные расходы

| Правило              | Как работает                                              |
|----------------------|-----------------------------------------------------------|
| Виды товаров         | `ExpenseKind.mandatory` / `optional` / `gift` (`items.json`) |
| Когда можно купить   | только фаза `playing` и `canAfford`                       |
| Списание             | `balance -= price` через `clampBalance` (минус запрещён)  |
| Учёт факта           | `mandatorySpent` / `optionalSpent` / `giftSpent` += price |
| Влияние на питомца   | `hunger` / `mood` += дельты, clamp `0…100`                |
| Перерасход корзины   | `spent > planCap` (в т.ч. при `planCap = 0`) → `mood − 3` |

## 5. Накопления и финансовые цели

| Действие           | Метод / условие                                      | Эффект                         |
|--------------------|------------------------------------------------------|--------------------------------|
| Выбор цели         | `goalsForProfile` + `goals.json` (`ageTracks`)       | цель активна                   |
| Пополнение копилки | `transferToSavings(amount)` только в `playing`       | баланс → `savingsBalance`, `fact.saved +=` |
| Снятие без подтверждения | `confirmed ≠ true`                             | предупреждение                 |
| Снятие после подтверждения | только `playing`; `withdrawFromSavings`      | `mood − 5`, **`fact.saved` уменьшается** (не ниже 0) |
| Достижение цели    | не в `planning`; `savingsBalance ≥ cost` → `claimGoal` | списание, `mood +18`, `★ +5` |
| Оценка срока       | `ceil((cost − savings) / avg)`                       | `avg` = план копилки или `15`  |

## 6. Проверка средств и запрет минуса

```text
canAfford(profile, price)  ⇔  price ≥ 0  ∧  balance ≥ price
clampBalance(v)            =  max(0, v)
clampHunger(v)             =  clamp(v, softHungerFloor=10, 100)
```

При нехватке денег покупка или пополнение копилки возвращают `ok: false` и сообщение «Не хватает N монет…».

## 7. План vs факт

```text
mandatoryOk    = fact.mandatory ≥ round(plan.mandatory × 0.7)
               ∧ fact.mandatory > 0

tolerance      = max(15, round(plan.total × 0.15))

planClose      = |fact.total − plan.total| ≤ tolerance
               где fact.total = mandatory + optional + saved + gift

savedOk        = fact.saved > 0

wasGoodPeriod  = mandatoryOk ∧ (savedOk ∨ planClose)
```

Реализация: `GameEconomy.comparePlanFact` → `PlanFactReport`.  
UI: экран итога периода + строки план/факт в магазине и бюджете.

## 8. Игровые периоды

Фазы: `planning` → `playing` → `summary` → следующий `planning`.

- **Демо-режим** (`demoMode = true`, по умолчанию): периоды идут сразу.
- **Обычный режим**: после `closePeriod` ставится пауза `normalPeriodCooldown` (2 минуты); `startNextPeriod` ждёт разблокировки. Прогресс не обнуляется.
- Бонус за вход: `claimDailyLogin` (+5 монет раз в календарный день). Пропуск дня не штрафует.
- Родительские монеты: `grantParentCoins` (+20, лимит 100 на профиль).

Стадии питомца: 1 «Малыш» → 2 «Растущий» → 3 «Чемпион» (`goodPeriodsPerStage = 2`).

`nextAction` перед `finishPeriod` требует отложить в копилку (иначе период не «хороший» и стадия не растёт). Копилку можно пополнять и без выбранной цели.

| Событие           | Метод                                      |
|-------------------|--------------------------------------------|
| Подтвердить план  | `confirmPlan`                              |
| Завершить период  | `closePeriod`                              |
| Начать следующий  | `startNextPeriod` (+ доход, `hunger − 8` с полом 10) |

Демо-режим: переходы без календарных сроков.

## 9. Задания: награды и логика

Выдача набора: `pickPeriodQuests` — по одному квесту на тему (бюджет / копилка / покупки) + доп. по треку.

| Событие        | Эффект                                              |
|----------------|-----------------------------------------------------|
| Неверный ответ | задание не закрывается; XP+3 **только за первую ошибку** по этому квесту в периоде; mood−3 (−1 у `junior`); комбо = 0 |
| Верный ответ (период) | закрытие; монеты; XP; ★; mood+8 (+4 при комбо ≥ 3) |
| Верный ответ (каталог / практика) | XP ≈ half; mood+3; **без монет и ★**; закрытие на период |

### Монеты за верный ответ в задании периода

```text
reward = option.reward
       + comboBonus                 // streak≥2: (min(streak,5)−1)×2
                                    // junior: comboBonus ≤ 4
       + difficulty.starReward × 2
       + periodBonus                // +4, если есть набор периода
       + skillBonus                 // (level темы − 1), max 5
```

### Награды по сложности

| Сложность | ★ | XP |
|-----------|---|----|
| easy      | 1 | 10 |
| medium    | 2 | 18 |
| hard      | 3 | 28 |

## 10. Состояние и рост питомца

Статы: `hunger`, `mood` ∈ `[0, 100]`; сытость при штрафах не ниже `10`.

### При закрытии периода

| Условие                 | Последствия                        |
|-------------------------|------------------------------------|
| `!mandatoryOk`          | mood−10, hunger−15 (пол 10)        |
| `mandatoryOk`           | ★+1                                |
| `savedOk`               | mood+5, ★+1                        |
| `planClose`             | ★+1; иначе mood−4                  |
| все квесты периода      | ★+2, balance+10, mood+5            |
| ≥2 квеста периода (не все) | ★+1, mood+3                     |

### Рост стадии

```text
если goodPeriodStreak ≥ 2 и stage < 3:
  stage += 1
  streak = 0
  ★ += 2
```

Покупки меняют сытость и настроение сразу.  
Итог периода и серия «хороших» периодов определяют рост стадии.

## 12. Демо-сценарий за 3 периода (для жюри)

1. План → задания периода → еда (mandatory) → копилка → `closePeriod` (хороший период).  
2. `startNextPeriod` (+доход) → снова хороший период → **стадия 2**.  
3. Цель junior (`treat` / `toy_box`) достижима быстрее дорогих senior-целей.

## 13. Блок «Учёба» (уроки по возрасту)

Контент: `assets/content/lessons.json`. Экран: `lib/features/learn/learn_screen.dart`.

| Трек | Лицо блока | Фокус уроков |
|------|------------|--------------|
| junior | Школа Финни | нужное/желаемое, копилка понемногу, «хватает ли» (+ игровые сценарии) |
| middle | Мастерская плана | три корзины, сравнение цен, расчёт периодов |
| senior | Штаб решений | сюрпризы, план vs факт, импульс у цели |

```text
completeLesson (верный ответ впервые):
  balance += rewardCoins
  skills += rewardXp по теме
  stars += 1, mood += 5
  completedLessonIds += id
```

Повтор урока — без повторной награды. `featuredLesson` ротирует незавершённые по номеру периода.
