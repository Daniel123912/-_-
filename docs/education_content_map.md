# Карта образовательного контента

Связь механик «Питомец Финни» с компетенциями базового уровня (Единая рамка, раздел 6) и контентом в JSON.

| Навык (рамка) | Как учим в игре | Уроки (`lessons.json`) | Задания (`quests.json`) |
|---------------|-----------------|------------------------|-------------------------|
| Бюджет: расходы ≤ доходам | План периода, остаток, запрет минуса | `l_j_need_want`, `l_m_*`, `l_s_plan_fact` | тема `budget`, интерактив `q_sort_*` |
| Нужное vs желаемое | Корзины плана + магазин mandatory/optional | `l_j_need_want`, `l_s_priority` | `q_budget_*`, `q_sort_three_baskets` |
| Покупки при ограниченном бюджете | Магазин, отказ при нехватке, скидка ≠ нужда | `l_j_enough`, `l_m_discount` | тема `purchases`, `q_sort_shopping_day` |
| Цель и регулярные накопления | Копилка, цели, claim, снятие с подтверждением | `l_j_piggy`, `l_m_goal_pace` | тема `savings` |
| Оценка решений | Итог периода план/факт, feedback, soft fail | `l_s_plan_fact`, `l_m_find_error` | `q_sort_plan_vs_fact` |
| Участие взрослого | Раздел взрослого: прогресс, демо, сброс | — | барьер + панель |

## Форматы обучения

1. **Уроки** — история → шаги → мини-проверка (XP + немного монет, один раз).
2. **Задания периода** — после плана; верный ответ даёт монеты/★/XP (п. 2.5.8 + Q&A).
3. **Практика каталога** — XP без монет (без фарма).
4. **Интерактив `sort_buckets`** — ребёнок сам раскладывает карточки по корзинам (не только выбор из списка).

## Возрастные треки

| Трек | Подпись в UI | Сложность заданий | Фокус уроков |
|------|--------------|-------------------|--------------|
| junior | 7–8 лет · Попроще | только easy, в основном `q_j_*` | нужное/желаемое, копилка, «хватает ли» |
| middle | 9–10 лет · Средне | easy + medium | план, скидки, скорость цели |
| senior | 11 лет · Посложнее | easy + medium + hard | план/факт, приоритеты |

Фильтрация: `questsForProfile` / `lessonsForProfile` + `allowedDifficulties`. Числовые «лёгкие» задания без `junior` в `ageTracks` не попадают к 7–8.
