# Архитектура решения

Продукт: **Питомец Финни** — офлайн-прототип игрового сервиса финансовой грамотности для детей 7–11 лет (ТЗ Департамента финансов города Москвы, задача «Город 6»).

Серверной части нет: приложение полностью клиентское. Учебный контент отделён от UI и загружается из JSON.

---

## 1. Стек

| Слой | Технология | Версия / заметка |
|------|------------|------------------|
| UI / клиент | Flutter | 3.47.x (stable) |
| Язык | Dart | SDK ^3.13.3 |
| Состояние | `flutter_riverpod` | ^3.4.3 |
| Локальное хранение | `shared_preferences` | JSON-профиль + резервная копия |
| SVG / шрифты / звук | `flutter_svg`, локальные TTF, `audioplayers` | ассеты в `assets/` |
| Package / applicationId | `ru.moscow.finny.pet` | Android |
| Версия приложения | `1.0.0+1` | `pubspec.yaml` |

Целевая платформа обязательной сдачи: **Android** (API 26+, ОЗУ ≥ 3 ГБ). Web (Chrome) — для удобной демонстрации и разработки.

                            │ Riverpod
┌───────────────────────────▼─────────────────────────────┐
│  state/game_controller.dart                             │
│  оркестрация действий → домен → сохранение              │
└───────┬─────────────────────────────┬───────────────────┘
        │                             │
┌───────▼──────────┐        ┌─────────▼──────────────────┐
│  domain/         │        │  data/profile_repository   │

        │

### Слои

| Каталог | Назначение |
|---------|------------|
| `lib/domain/` | Чистые правила: баланс, план, покупки, копилка, квесты, периоды, рост питомца |
| `lib/data/` | Сериализация / загрузка / сброс профиля |
| `lib/content/` | Парсинг JSON-контента (товары, цели, задания, уроки, питомцы) |
| `lib/state/` | `GameController` — единая точка мутаций профиля |
| `lib/features/` | Экраны и виджеты |
| `lib/theme/`, `lib/fx/` | Тема, цвета, короткие звуки/хаптик |
| `assets/content/` | Учебный контент без пересборки логики |
| `test/domain/` | Юнит-тесты формул экономики |

## 3. Поток данных (игровой цикл)

1. Онбординг → создание питомца (внешность, имена, возрастной трек).
2. Фаза `planning`: распределение баланса по корзинам → `confirmPlan`.
3. Фаза `playing`: задания периода, покупки, пополнение копилки.
4. Фаза `summary`: план vs факт, обратная связь, состояние питомца.
5. `startNextPeriod`: доход, новый план, ротация заданий.
6. После каждого значимого действия — `ProfileRepository.save`.

## 4. Обновление учебного контента

Контент лежит в `assets/content/`:

| Файл | Содержимое |
|------|------------|
| `items.json` | товары магазина |
| `goals.json` | цели накопления |
| `quests.json` | задания (в т.ч. `sort_buckets`) |
| `lessons.json` | уроки блока «Учёба» |
| `pets.json` | модели / цвета / глаза / аксессуары |

Чтобы добавить урок или задание, достаточно расширить JSON (с соблюдением схемы полей в `models.dart`) — без изменения доменных формул. Фильтрация по возрасту: `ageTracks` + `AgeTrack.allowedDifficulties`.

---

## 5. Серверная часть

**Отсутствует.** Нет API, аккаунтов, синхронизации и сетевых запросов в release-сборке. Спецификация OpenAPI не требуется.
