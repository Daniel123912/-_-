## B. Ручные кейсы (Android)

| ID | Шаги | Ожидание |
|----|------|----------|
| M1 | Установка APK, холодный старт | ≤ 5 с до UI |
| M2 | Онбординг + создание питомца | ≥ 2 различимые внешности |
| M3 | План → задания → покупки → копилка → итог | Полный цикл периода |
| M4 | Покупка без средств | Отказ + текст |
| M5 | Ошибка в задании | Можно исправить; есть объяснение |
| M6 | Kill app → reopen | Профиль на месте |
| M7 | Демо: 2–3 периода подряд | Без тупиков |
| M8 | Сброс профиля | Онбординг снова |
| M9 | Airplane mode | Основной цикл работает |
| M10 | Release: список разрешений | Нет лишнего INTERNET в main |
