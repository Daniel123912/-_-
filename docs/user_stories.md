## Acceptance criteria (шаблон для Must-историй)

Для каждой Must-истории минимум:

1. **Given** предусловие из UC  
2. **When** действие пользователя  
3. **Then** наблюдаемый результат + сохранение (если мутация)  
4. **And** нет отрицательного баланса / нет обхода фазы  

Детальные тест-кейсы: [`test_cases.md`](test_cases.md).
