# Лицензии и сторонние материалы

ТЗ §5 п. 12. Проект — учебный прототип хакатона; коммерческая публикация потребует финальной проверки лицензий ассетов командой.

---

## 1. Код приложения

| Компонент | Лицензия / условие |
|-----------|-------------------|
| Исходный код `lib/`, `test/`, конфиги проекта | Собственная разработка команды (права — у команды / по регламенту хакатона) |
| Flutter / Dart SDK | [BSD-3-Clause](https://github.com/flutter/flutter/blob/master/LICENSE) |
| Сгенерированные платформенные обвязки (`android/`, `ios/`, `web/`) | Шаблон Flutter (BSD-style) |

---

## 2. Зависимости pubspec (runtime)

| Пакет | Назначение | Типичная лицензия* |
|-------|------------|-------------------|
| `flutter` / `cupertino_icons` | UI | BSD / MIT |
| `flutter_riverpod` | состояние | MIT |
| `shared_preferences` | локальное хранение | BSD-3 |
| `path_provider` | пути ФС | BSD-3 |
| (локальные TTF) | Fredoka, Nunito в `assets/fonts/` | Шрифты — OFL (SIL); пакет `google_fonts` не используется в рантайме |
| `flutter_svg` | SVG питомцев | MIT |
| `audioplayers` | короткие WAV | MIT |

\*Точные тексты — в `LICENSE` пакетов на pub.dev / в кэше `.pub-cache` после `flutter pub get`. Dev: `flutter_test`, `flutter_lints`.

## 4. Изображения и звуки

| Путь | Описание | Права |
|------|----------|--------|
| `assets/images/pets/*.svg`, `thumbs/*.png` | питомцы | созданы / подготовлены для проекта |
| `assets/images/shop/*.png` | товары магазина | созданы / подготовлены для проекта |
| `assets/images/room_*_bg.png`, `pet_room_bg.png` | фоны комнат | созданы / подготовлены для проекта |
| `assets/images/pet.svg` | запасной ассет | для проекта |
| `assets/sounds/*.wav` | purchase / save / success / soft_fail | коротко сгенерированы / подготовлены для проекта |
| Material Icons (Flutter) | системные иконки UI | Apache 2.0 (Material) |

Сторонние стоковые наборы с запретом на модификацию / обязательным атрибутом в UI **не используются** как основа механики. При замене ассетов перед публикацией в RuStore обновить эту таблицу.

---

## 5. Учебные формулировки

Тексты заданий и уроков составлены командой с опорой на открытые просветительские формулировки (портал «Открытый бюджет», «Финансовая культура» Банка России) **без копирования охраняемых фрагментов целиком**. Компетенции сопоставлены с Единой рамкой (см. `education_content_map.md`).

---

## 6. Материалы организатора

ТЗ, Q&A и методические материалы хакатона используются только в рамках, допускаемых организатором; в репозиторий продукта не включаются как часть распространяемого APK.
