### Доработки поверх MVP

- Снятие из копилки корректирует `fact.saved` и только в фазе `playing`
- План с `mandatory ≤ 0` отклоняется
- Каталог заданий = практика (XP без монет)
- XP за ошибку один раз на квест в периоде; мягче штраф mood у junior
- Цели с `ageTracks` + дешёвые цели для 7–8 лет
- Навык темы даёт до +5 монет; доход junior = senior (+5)
- Мягкий пол сытости = 10; допуск план/факт относительный

## Как устроен игровой цикл (кратко)

1. Старт профиля → стартовый баланс, фаза **planning**.
2. Ребёнок распределяет бюджет → `confirmPlan` → фаза **playing**, выдаются задания.
3. Задания, покупки, пополнение копилки → меняются баланс, факт, сытость/настроение.
4. `closePeriod` → сравнение план/факт, награды/штрафы, возможный рост стадии → фаза **summary**.
5. `startNextPeriod` → доход на баланс, новый период, снова **planning**.

Подробные формулы: [`economy_rules.md`](economy_rules.md).

## Что не входит в эту часть

- Раздел для взрослого (барьер, демо-сброс) — использует профиль, но не является ядром экономики.
- Тексты заданий и картинки — лежат в `assets/content/` (контент отдельно от логики).
