# Разрешения Android, данные и удаление профиля

ТЗ §5 п. 9.

---

## 1. Разрешения

| Сборка | Разрешения |
|--------|------------|
| **Release** (`android/app/src/main/AndroidManifest.xml`) | **Нет** `INTERNET` и иных чувствительных разрешений |
| Debug / Profile | `INTERNET` только для hot reload / отладки Flutter |

Release APK работает **полностью офлайн**. Нет камеры, микрофона, геолокации, контактов, уведомлений push.

Package: `ru.moscow.finny.pet`.

---

## 2. Собираемые данные

| Данные | Где | Передаются на сервер? |
|--------|-----|------------------------|
| Имя игрока и питомца (произвольные строки) | локально, SharedPreferences | Нет |
| Внешность питомца, баланс, копилка, прогресс | локально | Нет |
| Выбранный возрастной трек | локально | Нет |
| История покупок периода, XP, уроки | локально | Нет |

**Не собираются:** email, телефон, фото, геолокация, идентификаторы рекламы, аккаунты.

Нет аналитики третьих сторон, нет рекламных SDK, нет реальных платежей.

Шрифты Fredoka и Nunito лежат в `assets/fonts/` и подключаются локально — сеть для UI не нужна. Логика игры и прогресс от сети не зависят.

## 3. Удаление профиля

1. Главный экран → иконка раздела взрослого.
2. Арифметический барьер (защита от случайного входа ребёнка).
3. Кнопка **«Сбросить тестовый профиль»** → диалог подтверждения.
4. Вызов `GameController.resetProfile()` → `ProfileRepository.clear()` удаляет ключи `finny_profile_v1` и `finny_profile_v1_backup`.
5. Приложение возвращается к онбордингу / созданию питомца.

Дополнительно: удаление приложения с устройства стирает локальные данные SharedPreferences.

---

## 4. Демо-режим и тестовые данные

В разделе взрослого:

- **Демо-режим** — периоды и обновление заданий без ожидания реального времени (для экспертов).
- При выключенном демо: пауза между периодами ~2 мин, ротация заданий ~5 мин.
- Сброс профиля — чистый тестовый старт без остатков предыдущего прогресса.
