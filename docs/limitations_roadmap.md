# Ограничения прототипа и план развития

ТЗ §5 п. 11.

---

## 1. Известные ограничения MVP

| Область | Ограничение |
|---------|-------------|
| Платформа | Обязательный фокус — Android; iOS не в объёме сдачи |
| Сеть / аккаунты | Нет облачной синхронизации между устройствами |
| RuStore | Черновик карточки готов; публикация в стор во время хакатона не выполнялась |
| Звук | Тумблер в разделе взрослого; при ошибке воспроизведения — хаптик/тишина |
| Шрифты | Fredoka + Nunito запечены в `assets/fonts/` (офлайн) |
| Доступность | Нет полного аудита TalkBack / крупных масштабов шрифта на всех экранах |
| Контент | Объём заданий/уроков выше минимума ТЗ, но не «полный курс» школьной программы |
| Подпись APK | Для магазина нужен отдельный release-keystore команды |
| Иконка витрины | Иконка 512×512 и финальные скриншоты RuStore — подготовить к загрузке на платформу |
| Видео | Резервная запись демонстрации ≤ 3 мин — отдельный артефакт сдачи (не презентация) |

---

## 2. Что уже сверх минимума

- 150+ заданий, интерактив «разложи по корзинам»
- Уроки с мини-проверкой и XP
- Возрастные треки и фильтрация сложности
- Комбо, звёзды, навыки по темам
- Демо-режим и cooldown вне демо
- Раздел взрослого: прогресс, начисление, челлендж, сброс
- Юнит-тесты доменной экономики
- Web-запуск для удобной демонстрации

---

## 3. План дальнейшего развития

### Ближайший горизонт (после финала)

1. Reduce motion / крупный шрифт в настройках взрослого.
2. Запечённые шрифты и финальная иконка/скриншоты для RuStore.
3. Подписанный APK и черновая карточка в кабинете RuStore.
4. Расширение словаря терминов и уроков по Единой рамке компетенций.

### Средний горизонт

5. Больше целей и сезонных наборов заданий без смены кода.
6. Улучшение TalkBack-семантики и контрастных тем.
7. Опциональный экспорт прогресса для родителя (локальный отчёт без облака).

### Вне границ текущего ТЗ (осознанно не делаем)

- Реальные платежи и реклама
- Сбор персональных данных и аккаунты детей
- Социальные рейтинги и чаты
