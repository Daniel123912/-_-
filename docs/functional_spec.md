# Функциональная спецификация (ФТ)

**Продукт:** Питомец Финни  
**Уровень:** требования к поведению системы (WHAT), без привязки к виджетам  
**Трассировка к ТЗ:** колонка «ТЗ» → п. 2.5.* / §5 / §7  
**Реализация:** см. [`requirements_matrix.md`](requirements_matrix.md), код в `lib/`

Приоритеты: **Must** — обязательно для приёмки MVP; **Should** — сильно желательно; **Could** — усиление / сверх минимума.

---

## 1. Общие правила

| ID | Требование | Приоритет | ТЗ |
|----|------------|-----------|-----|
| FR-GEN-01 | Система работает как гостевой офлайн-клиент без регистрации | Must | 2.5.1 |
| FR-GEN-02 | После значимого действия прогресс сохраняется локально | Must | 2.5.13 |
| FR-GEN-03 | Учебный контент загружается из JSON и не зашит в формулы экономики | Must | 2.5.14 |
| FR-GEN-04 | Баланс не может стать отрицательным | Must | 2.5.4 |
| FR-GEN-05 | Критичная обратная связь всегда доступна текстом | Must | 2.5.9, §3.6 |
