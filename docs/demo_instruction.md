# Инструкция для экспертов: установка, демо, сброс

ТЗ §7.2 (инструкция). Презентацию не заменяет — только запуск и проверка сценария.

---

## 1. Установка

1. Получите `app-release.apk` (сборка: см. [`build_guide.md`](build_guide.md)).
2. На Android-устройстве (API 26+, ≥ 3 ГБ ОЗУ) разрешите установку из неизвестных источников / через `adb`:

```bash
adb install -r app-release.apk
```

3. Запустите **Питомец Финни** (`ru.moscow.finny.pet`).
4. Первый экран должен появиться roughly за ≤ 5 с (холодный старт).

Альтернатива без APK: `flutter run -d chrome` из корня репозитория (см. README) — удобно для просмотра UI; **официальная проверка по ТЗ — на физическом Android**.

---

## 2. Демонстрационный сценарий (Приложение А)

Рекомендуется сразу включить **демо-режим** (см. §4), чтобы пройти 2–3 периода подряд.

| Шаг | Действие | Что показать |
|-----|----------|--------------|
| 1 | Онбординг | Три типа решений |
| 2 | Создание питомца | Внешность, имена, трек «попроще/средне/посложнее» |
| 3 | Главный экран | Баланс, копилка, состояние, подсказка |
| 4 | План бюджета | Нужное / желаемое / копилка (и при желании «Подарить») |
| 5 | Задания | ≥1 верный ответ + объяснение; при ошибке — исправление |
| 6 | Магазин | Обязательная и необязательная покупка; отказ при нехватке |
| 7 | Копилка | Цель, пополнение, снятие с подтверждением |
| 8 | Итог периода | План vs факт, изменение питомца |
| 9 | Следующий период | В демо — без ожидания |
| 10 | Перезапуск приложения | Прогресс сохранён |
| 11 | Раздел взрослого | Прогресс + сброс |

---

## 3. Демо-режим

1. На главном — иконка взрослого.
2. Решите простой арифметический барьер.
3. Включите переключатель **«Демо-режим»**.

Эффект: периоды и обновление набора заданий **без** паузы ~2 / ~5 минут. Для «реалистичного» темпа переключатель можно выключить.

---

## 4. Сброс профиля и тестовые данные

В разделе взрослого → **«Сбросить тестовый профиль»** → подтвердить.

Удаляются локальные ключи профиля; приложение возвращается к онбордингу. Подходит для повторной демонстрации «с нуля».

Родитель также может начислить монеты / задать челлендж копилки — опционально для показа роли взрослого.
