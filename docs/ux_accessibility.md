# UX/UI и доступность

Обоснование решений прототипа «Питомец Финни» (ТЗ §5 п. 8, §3.6).

---

## 1. Принципы UX

| Решение | Зачем |
|---------|--------|
| Механика питомца | Понятная детям метафора последствий: решения по бюджету меняют настроение, сытость и рост |
| Три корзины плана (+ «Подарить») | Явный выбор между обязательным, желаемым и накоплением — не «нажимай правильную кнопку» |
| Обратная связь текстом (`lastFeedback`) | Ошибка = учебная ситуация; критичная информация не только звуком |
| Мягкий fail | Неверный ответ не закрывает задание; можно исправить |
| Возрастные треки «попроще / средне / посложнее» | Формулировки без давления «ты маленький/глупый» |
| Раздел взрослого за арифметическим барьером | Прогресс и сброс недоступны ребёнку случайно |
| Демо-режим | Экспертам и жюри — полный цикл без ожидания реальных минут |
| Контент в JSON | Расширение уроков/заданий без переделки UI |

---

## 2. Визуальный язык

- Тёмная игровая палитра (фиолетовые комнаты, золотые акценты) — «игровая комната», не банковский кабинет.
- Крупные кнопки действий на главных шагах (план, покупка, ответ).
- Шрифты: **Fredoka** (заголовки) + **Nunito** (текст) из `assets/fonts/` — офлайн, без загрузки при старте.
- Иконки/иллюстрации питомца и магазина — собственные SVG/PNG в `assets/images/`.
- Фон комнат по разделам (`room_*_bg.png`) — ориентация «где я сейчас».

---

## 3. Навигация и подтверждения

- Главный экран — хаб: баланс, копилка, состояние, «сейчас важно».
- Покупка, снятие с копилки, сброс профиля — через диалог подтверждения.
- Единый паттерн возврата (AppBar / системная кнопка «назад»).
- Контраст текста на тёмных карточках: светлый ink на purple/card.

---

## 4. Доступность (реализовано / частично)

| Требование ТЗ | Статус в прототипе |
|---------------|--------------------|
| Контраст текста и фона | Светлый текст на тёмных панелях; акценты gold/mint |
| Единообразная навигация и возврат | Material 3 + общие виджеты `common.dart` |
| Критичная информация не только звуком | Всегда текст feedback / SnackBar / диалог |
| Звуки можно отключить | Тумблер «Звук» в разделе взрослого (`AdultPanelScreen` → `setSoundEnabled`). При выключении остаются хаптик/тишина |
| Подтверждение разрушительных действий | Сброс профиля, снятие с копилки, покупки |
| Масштаб шрифта системы | Flutter учитывает системный textScale; экстремальные значения не тестировались на всех экранах |

---

## 5. Этичность мотивации

- Нет «смерти» питомца и стыда за ошибку.
- Пропуск дня не штрафует (бонус за вход без наказания).
- Настроение/сытость имеют мягкий пол; ребёнок может восстановиться разумными решениями.
- Нет реальных платежей, рекламы, чатов и рейтингов давления.
