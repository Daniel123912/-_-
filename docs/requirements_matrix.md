## Логика заданий (усилитель для жюри)

| № | Правило |
|---|---------|
| 1 | Задания открываются **только после плана** |
| 2 | На период выдаётся набор: бюджет / копилка / покупки + доп. по треку |
| 3 | Неверный ответ **не закрывает** задание — можно исправить (XP за ошибку 1 раз) |
| 4 | Верный ответ периода: монеты, XP, звёзды, комбо, бонус навыка |
| 5 | Каталог = практика: XP без монет |
| 6 | Все квесты периода → бонус при закрытии периода |
| 7 | В новом периоде задания можно пройти снова (ротация) |

## Игровая и финансовая логика (чеклист)

| Возможность                         | Реализация |
|-------------------------------------|------------|
| Стартовый баланс                    | `AgeTrack.startingBalance` / `PlayerProfile.fresh` |
| Начисление валюты                   | `incomeForTrack` + награды квестов |
| Заработок за задания                | `completeQuest` |
| Распределение бюджета               | `confirmPlan`, `recommendedPlan` |
| Обязательные / необязательные расходы | `ExpenseKind` + `purchase` |
| Накопления и цели                   | `transferToSavings`, `claimGoal` |
| Проверка средств / запрет минуса    | `canAfford`, `clampBalance` |
| План vs факт                        | `comparePlanFact`, экран итога |
| Периоды и завершение                | `closePeriod`, `startNextPeriod` |
| Состояние и стадии питомца          | дельты статов + `applyStageProgress` |
| Награды и последствия               | ★ / XP / mood / hunger + `lastFeedback` |
| Связь финансов с питомцем           | покупки и итог периода меняют статы и рост |
